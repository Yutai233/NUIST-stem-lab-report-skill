# 仿真执行证据与验收

## 三态

- **PASS**：实际执行且满足声明的检查条件，绑定可定位证据。
- **FAIL**：执行过但未满足条件，保留失败数据、错误和修复前状态。
- **UNVERIFIED**：未执行、执行中断、工具不可用或证据不足；不能按理论预期填成 PASS。

这些状态逐检查项登记，不用一个笼统的“实验成功”覆盖缺项。修复后重新运行的 PASS 不抹去历史 FAIL。

XML 自动化分四道门槛分别登记：生成及结构检查、原生求解及数据有效性、课程物理验收、保存后重开复验。执行器返回成功仅证明其声明的执行检查通过；后两项仍须单独核验。整体 PASS 要求本次全部必做项通过；存在未验证必做项为 PARTIAL，未恢复的必做项失败为 FAIL。用户未要求的 GUI 不属于缺项。

## 最小运行清单

每次任务生成自己的 run_manifest.json，至少包含：

- 任务范围、教师要求来源、运行日期、软件/接口位数及版本；许可只能记录可用状态，不能记录密钥。
- 输入路径和 SHA-256、依赖版本/提交号、生成或修改了哪些对象、模型差异及数据单位。
- 每个工况的源、负载、扫描参数、分析类型、探针节点及电流正方向。
- 工程、原始求解输出、导出图、派生表的路径与 SHA-256；派生数据注明公式及原始来源。
- 每项检查的状态、阈值、实际误差、证据；保存后重开结果、失败记录、人工介入及未验证项。

## 不可混淆的证据

| 证据 | 支持的结论 | 不支持的结论 |
|---|---|---|
| XML 编解码 | 容器可读写 | 拓扑、模型、数值或 GUI 正确 |
| 软件原生网表 | 元件引脚与网络对应 | 全部器件动态行为正确 |
| 单频 AC 相量 | 指定工作点附近的单频线性响应 | 启动、非线性、动画或瞬态正确 |
| 瞬态原始采样 | 声明时间窗内的时域行为 | 自动满足稳态、采样精度或实物一致性 |
| 原生图纸导出 | 当前工程的可视图纸 | 桌面运行截图、仪表面板读数 |
| 保存重开再求解 | 所核对参数及结果可复现 | 未检查仪器和工况也已完成 |

RMS、相角和功率先确认峰值/RMS约定及电流方向。功率因数分清 P/(Urms*Irms) 与位移因数；非正弦波不能直接用 cos(phi) 代替。自适应采样使用时间加权积分，不按采样点数直接平均。AC 与瞬态或独立理论不一致时先定位原因，不为了贴合旧表而改数据。

使用 NI 本机素材生成的模板留在用户本机；不要把器件库、许可证或含身份信息的报告打包发布为公共 Skill 资源。

## 泛化、迁移与清理

软件流程、课程参数和任务实证分开保存。公共 Skill 放流程、接口契约及可传参执行器；频率、时长、工况数、探针名、器件修正及物理容差来自当前任务。没有跨器件/版本实跑的部分记为待适配，不称任意电路通用生成器。

用户要求整理或清理时：

1. 先核对当前入口、清单和依赖。保护原始材料、必要模板/vendor、最终工程、原始求解数据、复现脚本和关键失败证据。
2. 必须迁移的输入记录原路径、新路径和 SHA-256，更新当前入口后重跑；旧运行清单保留原样，以迁移记录解释历史路径。
3. 清理清单逐项记录路径、文件数、大小、用途及保留依据。名称带临时前缀不构成删除理由。
4. 检查最终绝对路径位于本次授权目录内，排除链接/重解析点，确认不包含被保留清单引用的唯一文件。Windows 优先移入回收站。
5. 清理后验证目标已移除、保护文件 hash 未变、源/安装版一致和复现入口可用；记录清理结果。不要把用户本地模板、依赖包或大批运行数据复制进公共 Skill。
