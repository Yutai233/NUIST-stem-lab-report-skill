# ADS 实验报告提示词

## 适用范围

用于 Keysight/Agilent ADS 射频系统级仿真实验，包括直接上变频发射机、一级或多级下变频超外差接收机、滤波器/放大器/混频器级联、谐波平衡（HB）、频率转换交流仿真、增益预算和噪声预算。每次必须从当前工程重新读取频率、功率、边带、模块参数和仿真控制器，不能沿用旧报告数值。

当前版式基准：用户确认 `ADS实验报告.docx` 为现阶段教师要求模板。该登记只适用于当前已知版本；若本次或后续收到新的教师模板、实验指导书、评分表或格式通知，必须以最新材料为准，并重新核对封面、章节、图表和提交要求。

## 建议结构

1. **实验目的**：只写本次要搭建、仿真和验证的 ADS 链路。
2. **实验原理**：根据当前拓扑说明上变频/下变频、和频与差频、边带选择、滤波和增益分配；涉及噪声预算时说明 Friis 关系及其适用条件。
3. **系统设计与参数设置**：给出原理图、端口/本振/终端、器件型号或模型、频率和功率参数表，注明单位和来源。
4. **仿真设置与结果**：分别说明 HB 频谱、频率转换 AC、增益预算、噪声预算或当前实际使用的控制器；每张曲线标注节点、变量、扫描范围和读数。
5. **结果分析与问题排查**：按“目标频率/功率是否出现—滤波器是否保留目标分量—预算路径是否完整—杂散/噪声/增益是否合理”分析。故障只写有记录的现象、排查和复测。
6. **总结**：结合当前链路说明频率规划、滤波、增益、噪声和动态范围之间的关系，不把仿真结论扩大为硬件性能结论。

## 专业核对点

- 对上变频核对 `f_RF = f_LO + f_IF` 或当前选定边带；对下变频核对 `f_IF = |f_RF - f_LO|`，并明确是高边带还是低边带。
- 频率单位必须统一，GHz、MHz 和 Hz 换算不能混用；频谱标记点、端口频率和本振频率应互相一致。
- 端口功率、放大器增益、混频转换增益、滤波器插入损耗和终端设置分别记录；不能把节点功率直接当成单级增益。
- 增益预算和噪声预算必须沿真实信号路径选择输入、输出和模块；预算曲线缺级时先检查路径，不用文字补齐。
- 杂散、镜像、LO 泄漏和压缩等只能在相应频谱或非线性模型证据存在时下结论；线性小信号模型不能证明真实功放线性度。

## 证据与输出

优先使用当前 ADS 工程、原理图截图、变量表、HB/AC/预算曲线和日志。没有运行记录时可写设置方法与理论预期，但应明确不是本次仿真结果。图题应说明节点和仿真类型，表格列出参数、单位和来源；不要把旧报告中的 2.4 GHz、300 MHz、20 MHz、11 MHz 或其他数值当作默认值。
