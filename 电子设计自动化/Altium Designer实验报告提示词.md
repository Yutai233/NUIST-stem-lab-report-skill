# Altium Designer 实验报告提示词

## 适用范围

用于 Altium Designer 原理图与 PCB 设计实验，包括原理图库、原理图、PCB 封装库、封装关联、Update PCB、网络类、设计规则、布局布线、铺铜和 DRC。当前实例包含 AD9236 电路设计与 STM32 最小系统两类任务；先识别实验对象，再按对应适配规则组织报告。

## 建议结构

1. **实验目的**：说明当前器件/系统和需要掌握的 AD 工程链路。
2. **实验任务与器件**：列出必做任务、主要器件、符号/封装名称、接口和提交成果；器件型号与封装以本次资料为准。
3. **原理图库与原理图设计**：记录符号绘制、引脚编号/名称、Designator、网络连接、封装指定和编译检查。
4. **PCB 封装与关联**：说明焊盘尺寸/间距、引脚 1 方向、丝印/阻焊要求、封装管理器映射和 Update PCB 结果；没有封装尺寸来源时不补写。
5. **PCB 设计**：说明板框、层、布局、网络类、线宽/间距规则、关键电源和地回流、布线、过孔和铺铜。
6. **检查、问题与总结**：记录编译、未连接网络、线宽/间距、短路、封装引脚和 DRC 检查结果；把“规则已设置”与“DRC 实际通过”分开。

## 实验对象适配

### AD9236 电路设计

按当前指导书核对 AD9236、AD8065、TL072、ICL7660、AMS1117-3.3 或其他实际器件的符号、封装、供电和模拟/数字网络。重点描述 TSSOP、SOP、SOT 等封装的引脚对应、PWR 网络类、GND 铺铜和 DRC，不默认采用任何实例的封装型号或线宽。

### STM32 最小系统

按当前指导书核对 MCU 型号、外部存储器、供电、复位、时钟、启动/下载和接口网络。重点描述高引脚数 MCU 的 LQFP 等封装、去耦和晶振布局、电源/地线宽、回流路径、飞线和 DRC；“最小系统”不自动等于已经上电运行，除非有板级照片、烧录或测试证据。

## 专业核对点

- 符号引脚编号必须与数据手册或教师资料一致，封装焊盘编号必须一一对应；不能因图面连线完整就推断映射正确。
- 原理图编译通过、封装管理器无缺失、Update PCB 成功、PCB DRC 通过是四类不同检查，分别记录证据。
- 电源网络、普通信号、时钟、复位、高速/敏感模拟网络的规则应按当前任务说明；示例中的 20 mil/10 mil 只能作为旧实例信息，不能自动复用。
- 布局布线截图要能看清板框、器件、走线、层和关键网络；铺铜后应复查间距、孤岛、未连接网络和 DRC。
- 只提供原理图或 PCB 截图时，不能推断已经完成编译、更新、铺铜或 DRC；无实物照片时不写焊接和上电结果。

## 证据与输出

优先使用当前 `.SchLib`、`.PcbLib`、`.SchDoc`、`.PcbDoc` 工程、编译/DRC 报告和原始截图。完整报告应将设计目标、软件检查结果和实物验证分开；缺少某一阶段证据时继续整理已有阶段，并在交付说明中列出未验证项目。
