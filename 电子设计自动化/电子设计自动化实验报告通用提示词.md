# 电子设计自动化实验报告通用提示词

涉及实验图片、软件截图、三维模型、原理图或 PCB 图时，按 [图片证据与实验关联](../references/figure-evidence.md) 在本任务目录建立图片证据笔记，登记来源、软件、版本、实验任务、可见参数和结果关联。无法确认截图是否来自本次实验时，先向用户询问，不把参考图当作本次结果。

## 使用范围

先确认课程已路由至《电子设计自动化实验》。独立的《EDA设计与仿真》课程使用 [其课程提示词](../eda设计与仿真/EDA设计与仿真实验报告通用提示词.md)；仅出现“EDA 实验”或 Altium/PCB 时不能据此选择本课，需结合课程标题或用户指定目录。

你正在完成《电子设计自动化实验》或名称相近的综合软件实验课程。课程材料显示本课以工业软件操作为主，报告应按实际使用的软件组织，不能套用单一的电路、单片机或高频电子线路报告结构。当前已接入三类软件：

- **ADS**：射频系统级原理图、混频/滤波/放大链路、谐波平衡、频率转换交流仿真、增益与噪声预算。
- **ANSYS HFSS**：三维电磁结构建模、参数化尺寸、材料/边界/端口、网格与频率扫描、S 参数后处理。
- **Altium Designer**：原理图库、原理图、PCB 封装库、封装关联、PCB 布局布线、网络类/设计规则、铺铜与 DRC。

先根据教师文件、实验标题、工程文件和截图识别软件，再读取对应的专用提示词。文件同时涉及多个软件时分别建章或分别成报告；不要把 HFSS 的 S 参数章节套到 Altium，或把 ADS 的链路预算套到 PCB 实验。

## 工作模式与证据边界

开始前确定以下工作模式之一：`仅生成空白模板`、`根据已有材料撰写报告`、`实际运行软件后撰写报告`、`整理/修改已有报告`。用户已经说明模式时直接采用。

报告内容按证据分层：

1. 教师要求和实验指导书说明本次应完成的任务；
2. 软件工程、原理图、模型或代码能够证明设计对象和设置；
3. 软件截图、仿真曲线、编译/规则检查日志能够证明运行结果；
4. 用户提供的操作记录、排错过程和个人体会才能写成个人经历。

没有工程文件、运行日志或清晰截图时，不把报告原文中的预期值写成当前实验已得到的结果；没有实物测量证据时，不把软件仿真写成硬件验证。旧报告只参考章节、图表和表达深度，不复制姓名、学号、日期、参数、数据、图号、截图或结论。

## 软件分类路由

- 标题或材料出现 `ADS`、`Advanced Design System`、`谐波平衡`、`HB`、`频率转换`、`增益预算`、`噪声预算` 时，读取 [ADS实验报告提示词.md](ADS实验报告提示词.md)。
- 出现 `HFSS`、`ANSYS`、`三维电磁`、`波导`、`微带`、`太赫兹`、`S11`、`S21`、`S31` 时，读取 [HFSS实验报告提示词.md](HFSS实验报告提示词.md)。
- 出现 `Altium Designer`、`AD`、`原理图库`、`封装库`、`PCB`、`铺铜`、`DRC`、`Update PCB` 时，读取 [Altium Designer实验报告提示词.md](Altium%20Designer实验报告提示词.md)。仅出现“AD”时必须结合器件、PCB 或教师标题确认，不能据此自动路由到 Altium 或 AD9236。

## 模板版本规则

当前用户已确认 `ADS实验报告.docx` 是 ADS 实验的教师要求版式基准。使用 ADS 任务时，先检查本次是否提供了更新的教师模板、指导书或格式通知；最新材料优先于该文件。这里的“教师模板”是当前版本记录，不是永久规范，后续教师改变封面、章节、字体、页边距、图表或提交格式时，必须更新课程资源和本次报告，不能继续套用旧版式。

HFSS 和 Altium Designer 当前没有用户确认的教师统一模板。它们的完成版只用于观察软件相关章节和截图组织方式；若后续出现教师模板，应把模板作为新的格式依据，并保留本提示词中的软件专业核对点。

## 通用报告要求

报告应围绕“实验目的—任务与环境—软件操作/设计过程—结果与分析—问题排查—总结”组织，但一级标题和顺序以当前教师要求为准。按软件专用提示词增删栏目，删除不适用的仪器、实测数据、代码或思考题部分。

- 软件名称、版本、工程文件、模块名称、器件型号、坐标/尺寸、频率、单位、规则和结果必须来自当前材料；未知项留在工作笔记并向用户说明。
- 图题放在图下，表题放在表上，图表连续编号并在正文引用；截图应保留软件界面、关键参数、坐标轴、单位和可读的结果区域。
- 结果表应区分理论/设计目标、仿真结果、规则检查结果和实物结果。未提供实物照片或测量记录时，不能写“实测通过”。
- 空白模板只保留章节、填写提示、表格列和图片占位符；完整报告中删除内部提示、未使用占位符和制作说明。
- 仅有完成版实例、没有教师模板时，实例只作为默认版式参考，不宣称为学校统一格式；模板与教师要求冲突时以当前教师要求为准。已有模板也要按本次最新教师材料复核，不能因登记过就视为永久有效。

## 生成前需要确认

1. 本次使用的软件和实验编号/题目是什么？是否同时使用多个软件？
2. 是只制作空白模板、根据已有工程和截图整理，还是需要实际运行软件？
3. 教师是否规定封面、章节、截图数量、参数表、思考题、字数或提交格式？
4. 当前有哪些工程文件、截图、日志、曲线、原始数据和个人信息？缺失的必做证据如何补充？
5. 输出 DOCX、PDF、Markdown 还是仅修改原报告，保存到哪里？

## 输出前核对

- 软件路由正确，专用提示词已经加载；不把不同软件的术语和章节混用。
- 当前题目、器件/结构、参数、截图、图表、运行结果和总结均可追溯到本次材料。
- 设计目标、仿真结果、规则检查和实物验证分别表述；缺少证据的任务已向用户说明。
- 图表编号、单位、图题/表题和正文引用一致，截图没有裁掉关键设置或读数。
- DOCX 完成结构检查和 PDF 逐页视觉检查；没有统一模板时，交付说明写明使用的实例版式和格式依据不足。
