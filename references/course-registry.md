# 南信大理工科课程资源登记表

本文件是课程资源选择的唯一总表。路径均相对于 Skill 根目录。当前表中的课程是已经接入的示例，后续新增理工科课程必须按照 [new-course-integration.md](new-course-integration.md) 完成接入。选择资源时先依据当前实验材料识别课程，再读取对应提示词和模板；不要只根据用户上传文件的名称猜测。

## 资源可信度边界

当前登记的提示词、模板和完成版实例是用户现有资源，不自动代表南信大官方规范。除非用户另行提供并确认来源，否则不要把其中的固定章节、字数、字体、行距、总结要求或版式描述为学校/学院的硬性规定。生成报告时，当前教师文件、实验指导书和评分标准优先。

当前实例目录只记录文件数量，没有统一登记作者类别、来源、学期、课程班级和教师确认状态。实例可用于观察版式和表达，但其个人信息、实验数据、参数、结论和独有章节均不具备跨实验复用资格。后续补充实例时，建议在课程目录中增加来源说明文件，至少记录：来源类别、适用课程/学期、是否教师示例、可借鉴范围和不可复用内容。

## 选择顺序

1. 当前教师要求或实验指导书明确写出的课程名称。
2. 当前任务内容中的专业关键词、软件、硬件和实验主题。
3. 用户指定的课程文件夹或模板。
4. 下表中的关键词和已有资源。

出现两个课程都可能适用时，先向用户确认；在确认前可以整理材料清单，但不要填充专业结论。

## 别名判定和歧义处理

- 课程正式名称、教师文件标题或用户明确指定的课程目录具有最高优先级；别名只用于辅助识别，不覆盖明确课程名称。
- 至少同时命中“课程别名/目录名”与一个有区分度的专业关键词，才可自动选择课程资源。只有“实验报告”“电子线路”“仿真”“CAD”“FPGA”“微机原理”等泛词时，不得自动路由。
- “微机原理”单独出现时可能指微机原理、单片机或计算机组成类课程；必须结合 Keil/C51/Proteus、芯片型号、端口/寄存器或用户指定目录确认。
- “电子线路”“电子技术实验”单独出现时可能指模电、高频或其他电路课程；必须结合放大器/运放、谐振/带宽、频率响应等主题确认。
- “FPGA”“HDL”“CAD”“Multisim”“MATLAB”是工具或主题词，不是单独的课程名；只有与课程别名、任务书标题或专业内容共同出现时才用于路由。
- “DSP”也可能指处理器硬件，“采样”“频谱”“MATLAB”与其他课程共有；结合明确课程名、用户目录和任务确定，不能仅凭 MATLAB 或 DSP 缩写套用数字信号处理报告结构。
- “EDA 实验”“EDA Lab”“电子设计”可能指电子设计自动化实验或 EDA设计与仿真；Altium/PCB/DRC 是两者共有内容，Multisim、序列检测器或正弦波也与数电/模电交叉。必须先按明确课程名、用户指定目录或任务书确定课程；只有共享简称和这些交叉关键词时询问，不能由软件直接定课。明确指定 EDA设计与仿真时使用其独立资源，不覆盖到已有 ADS/HFSS/Altium 课程。
- “电工电子技术实验”“通信原理实验”“嵌入式系统实验”等可能是本表未登记的独立课程，不得强行映射到电路、单片机或高频；按未登记课程流程处理。
- 两门课程得分接近或材料相互矛盾时，先向用户报告候选课程、命中依据和冲突点，再询问确认；确认前只能整理材料清单，不能生成专业结论。

## 实例使用规则

### 有多个实例

先提取每份实例的课程名称、实验主题、章节层级、封面字段、图表编号方式、字体/分页特点和结果分析写法，再与模板及教师要求比对。只保留多个来源共同出现、且没有被当前教师要求否定的格式特征。

### 只有一个实例

把它作为局部样例，不作为课程规范。可以参考版式、标题层级、图题/表题位置和表达口径；不得据此固定字数、固定实验章节、固定数据表或固定结论。

### 没有实例

不跨课程借用完成版报告。使用当前模板、教师要求和实验指导书建立结构；无法判断的格式写入待确认项，不能通过其他课程报告“补齐”南信大本课程的习惯。

### 实例来源记录

如果用户后续补充实例，优先在相应课程的 `example/` 文件夹中保存，并在任务记录或交付说明中注明来源类别（教师示例、本人旧报告、同学报告或其他来源）和可借鉴范围。除非用户要求，不需要把个人姓名写进最终报告。

## 未登记课程

如果用户提供的课程不在表中：

1. 先读取该课程的提示词、教师规范、模板和实例。
2. 以当前课程资料建立临时结构，不使用本表中其他课程的固定章节和专业规则。
3. 在生成前说明该课程尚未登记；完成任务后只在用户明确要求时再新增课程条目。
