# 图片证据与实验关联

本规则用于实验照片、截图、指导书插图、仿真图和数据绘图。完整报告涉及这些图片或多图对应时加载；局部换图只处理受影响部分，纯文字修改和仅封面标志不启动完整流程。

## 一、先登记，再使用

在本次任务工作目录创建 `图片证据笔记.md`，不把实验笔记写回 Skill。先浏览有关原图，再以稳定 ID（如 `IMG-001`）登记；ID 不随报告图号重排而改变。原图保留不覆盖，裁剪、旋转和拼图另存处理文件。

图片笔记用于辅助核对，不是正确答案。关键读数、开关/通道状态、单位和比较条件必须回看原图；不能只凭笔记、文件名、缩略图或前一次模型描述写结论。未登记的实验图片不得进入正文。无需把所有输入图都放进报告；不采用的图片简记原因即可。

采用 Markdown 条目而非只写宽表，便于记录依据和脚本读取。每张相关原图至少登记以下字段；不适用或不可辨认的项目如实记录，不猜填。

```markdown
## IMG-001

- 原始来源: 原文件路径；来自文档时注明文档路径、页码/原图号
- 来源性质: 本次实物照片／本次仿真截图／指导书或教材／数据绘图／待确认
- 图面可见信息: 直接看见的读数、单位、标签、通道及其位置
- 条件与依据: 条件内容；依据为图面、用户说明、日志或其他可追溯记录；未知项单列
- 实验任务关联: 对应本次哪项任务或观察
- 支撑论述: 该图能够支持的事实或比较
- 不确定性与边界: 看不清、来源冲突、尚未确认及不能支持的结论
- 采用状态: 待确认
- 处理文件: 处理后路径；未处理则填原路径；拼图注明其他 IMG ID 和子图标签
- 报告图号: 成稿后回填，例如图1；不入报告则填不适用
- 图题与正文引用: 成稿后回填实际图题及所在章节/段落
- 最终页码: 最新渲染后回填
- 核对结果: 原图、处理图、图注、正文及最终页面的核对状态
```

脚本读取 `## IMG-001` 及 `- 原始来源:`、`- 采用状态:`、`- 报告图号:` 等字段；允许全角冒号。采用状态使用 `采用`、`参考`、`不采用` 或 `待确认`。参考图实际入文时也登记报告图号；多个原图合成一幅图时可登记相同报告图号，不能因此误判为重复证据。

## 二、区分来源与用途

- 来源性质不等于图片用途。本次拍摄的书页仍属于指导书资料，不是本次实测；仪器界面截图也不单凭外观认定为本次测量。
- 无法确切判断指导书图与本次实测图时，直接询问用户，附图片 ID、路径及具体疑点。未收到答复可继续独立部分，但不将该图当作实测证据。用户确认后把说明写入笔记。
- 指导书/教材中的原理图、电路图、装置图可按来源用于原理说明；其中的曲线、波形也可作为明确注明来源的理论或参考对照，不能冒充本次实测。
- 数据绘图登记输入表格/数据文件及数据性质。依据指导书数值绘制的曲线仍是指导书数据绘图；重绘或改图题不会改变证据性质。

## 三、读数、条件与结论

- 分开记录直接可见事实、用户/日志提供的条件、计算结果、推断待核对和不可辨认信息，不把推断升级为事实。图题可使用图外已证实的条件，但要在笔记中记下依据。
- 保留单位、量纲、通道及测量类型。光标读数与自动测量值、当前值与平均/最大/最小值、峰峰值与有效值不得混用；只看清部分数字时不补齐。
- 同一结果的表、图、正文必须关联同一数据来源，检查单位、换算和比较条件。理论与实测、不同条件或独立测量可使用不同来源，但必须分别标识，不能机械要求所有材料数值相等。
- 对照结论需要条件变化和对应观测证据。两张照片本身不证明条件不同，同一张图包含多个明确标识的条件或另有可靠日志时也可以支撑比较；证据不足时缩小论述范围或询问用户。
- 不得用同一曲线重复裁剪冒充独立实验，也不得因图面“看起来像”某种状态就补写开关、操作或调试经历。

## 四、处理与成稿复核

1. 旋转、裁剪或拼图后核对坐标轴、图例、单位、仪器状态、关键读数是否仍可读，子图标签是否对应；不能裁掉与论述冲突的信息。
2. 插图后回填真实图号、图题、正文引用；回看实际插入的图，按“原始来源 → 处理图 → 成稿图 → 图题 → 正文论述”核对，不只检查生成脚本或文件名。
3. 检查相关表格、计算和正文引用的来源一致性；删图、换图、重排后同步所有引用，避免残留不存在的图号。
4. 导出最新 PDF 并逐页查看，回填页码，确认图题关联、打印尺寸下的读数和坐标可读，不以像素高或 DPI 达标代替实际可读性。

图片不够清楚时优先换图、保留必要区域或调整尺寸；来源或读数不明先询问用户。可选且无证据的论述可以删除并同步引用；必做内容缺证据时在对话中说明尚未完成，不能用泛化措辞掩盖缺失。

## 五、笔记与正式报告的边界

“保留不确定性，不自行补值或补过程”是工作规则，不是默认插入 Word 的正文。模型识图疑点、待确认清单、材料缺失和内部审查备注留在笔记，并在过程中或最终回复告知用户。正式报告只写有依据的专业内容；有证据的测量局限、误差和科学不确定性仍可正常分析。

空白模板或用户明确要求保留待补项的草稿可用占位符。其余情况不得把未知项编造成事实，也不得静默删除必做结果后声称报告完整；必要时保留可核验部分并说明交付尚未完整。

## 六、结构辅助检查

在 Skill 根目录运行（需要 Python 和 Pillow）：

```text
python scripts/audit_figures.py REPORT.docx --notes 工作目录/图片证据笔记.md --out 工作目录/图片检查.json
```

脚本只读检查正文中可识别的图号、引用、实际使用图片的完全相同内容、显示 DPI/纵横比预警及笔记登记。`--min-dpi` 默认为 150，是可调整的预警值，不是各课程统一硬门槛；完全相同内容只报警，不自动判定重复使用错误。不同裁剪或相似图不能靠哈希识别，仍需人工核对。

结果区分 `error`（明确结构错误）、`warning`（需复核）和 `unverified`（未验证）。退出码 `1` 表示发现明确错误，`0` 仅表示未发现明确结构错误，`2` 表示输入/输出不可处理。浮动图、文本框、子图、矢量格式和复杂编号等未支持项需人工检查，不能按通过处理。

脚本不证明来源真实性、图面与图注语义一致、表图文数值一致、图题同页或最终清晰度；不声称自动完成 OCR 或页面验收。运行后仍须按 [docx-pdf-qa.md](docx-pdf-qa.md) 回看原图和最终页面，修复明确错误并记录其余复核结果。
